## Interpretation and limits

- `requireSession` establishes a tenant-scoped session; `requireAuthorization` delegates to central `authorize()`. Location/resource scope is recorded independently.
- Absence of `requireAuthorization` does not itself mean an endpoint is unprotected: identity proof, provider authentication, buyer sessions, backup tokens and public reads use other trust paths.
- The route-level transaction boundary is normally the called store function. See `sqlite-dependency-map.json` for extracted SQL statements and transaction markers.
- Test candidates are filename/domain hints only. Exact test assertions and route invocation remain to be verified.
- No route extraction is approved by this characterization. URL prefixes and handler names are not canonical ownership evidence.
